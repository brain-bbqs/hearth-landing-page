# HEARTH Landing Page

The main landing page for the **HEARTH** (**H**ub for **E**xploratory **A**nalysis, **R**esource-sharing, **T**esting, and **H**ypothesis-generation) ecosystem.

A hub page linking out to the HEARTH suite of apps (starting with
[upload.brain-bbqs.org](https://upload.brain-bbqs.org)), built with
[Vite](https://vitejs.dev/) + TypeScript and deployed to GitHub Pages.

See [`docs/README.md`](docs/README.md) for development, testing, and
deployment instructions.
